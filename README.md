### 🌙 [Midnight Privacy-Preserving dApp](https://github.com/Its-prity/midnight)

A full-stack **zero-knowledge dApp on the Midnight Network** that shows Midnight's dual-state model in practice. A user enters a **private witness value**, a **Compact** circuit proves it's valid (`assert secret_increment > 0`) locally in the browser, and only the proof and the approved state change ever reach the public ledger. You can prove something is true without revealing it.

- 🔐 ZK smart contract in **Compact**, compiled to prover and verifier keys
- 👛 **Midnight Lace wallet** connect and disconnect through the DApp Connector API
- 📊 Live ZK-flow visualizer, ledger-state viewer and transaction audit log
- ✅ Automated tests and a **GitHub Actions** CI pipeline, deployed on **Vercel**
- 🗳️ Includes a full product proposal for **Midnight ZKVote**, a confidential secret-ballot governance system

### 🗳️ [Election AI Guide](https://github.com/Its-prity/Election-Process-Education-Ai-Agent01)

A **civic-tech and edtech AI assistant** that makes the U.S. election process easy to follow: primaries, the Electoral College, swing states and voting timelines. It runs on **Gemini 2.5 Flash**, which writes both the explanation and a matching **Mermaid.js diagram**, so complex processes come out as flowcharts rendered right in the chat.

- 🌍 Answers in **7 languages**, switchable in the app
- 🔊 **Text-to-speech** read-aloud through the Web Speech API
- 🗓️ Interactive election timeline and a chat assistant with a mock fallback
- ♿ Built for accessibility: semantic HTML, ARIA live regions, high contrast
- 🐳 Containerized with **Docker and Nginx** for **Google Cloud Run**

### ✈️ [Traveloop: AI Travel Planner](https://github.com/Its-prity/Travelloop)

A browser-based **travel-planning PWA** that covers a trip from start to finish: create a trip, build a day-by-day itinerary, keep notes, tick off a packing checklist, generate a PDF invoice and share trips with the community. **Loop**, a built-in Gemini-powered travel companion, gives suggestions based on the trip you're looking at. *(Team project)*

- 🧭 14 screens, including dashboard, itinerary builder, search, community, profile and admin panel
- ⚙️ **Next.js** backend with a REST API, **NextAuth** authentication and **Zod** validation
- 🗄️ **Supabase (PostgreSQL)** schema with 10 tables and **Upstash Redis** caching
- 🤖 **Loop** AI assistant powered by Google Gemini, with proactive tips
